# Clip Vault privacy policy

Last updated: 25 November 2026

ClipVault is a private tool used only by its owner to send short videos to the owner's own social media accounts. It is not offered to the public.

## TikTok

With the owner's permission, the tool reads the basic profile of the owner's TikTok account and uploads videos to that account as drafts. Access can be removed at any time in the TikTok app settings.

## YouTube and Google Drive

With the owner's permission, the tool uploads videos to the owner's own YouTube channel, reads that channel's basic details, looks up public information about YouTube videos, and has read-only access to the owner's Google Drive, from which it downloads only the files placed in its one input folder. Access can be removed at any time at myaccount.google.com/permissions.

ClipVault's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Storage and sharing

Sign-in tokens are kept on the owner's private server with restricted access, and are deleted when access is removed. The tool collects no data about viewers, followers or any other person. Data is not sold, shared, used for advertising or used to train AI models.
